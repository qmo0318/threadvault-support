隱私政策

更新日期：2026-10-15。說明我們如何處理你的資料。

我們收集哪些資料

你連接 Threads 後，ThreadVault 會透過 Meta 官方 API 讀取你的帳號識別碼、使用者名稱、大頭貼，以及你本人貼文和回覆的文字、時間、原文連結與媒體資訊。我們也會建立隨機的 App 登入識別碼，記錄同步狀態及時間。我們不要求你提供手機號碼，也不申請讀取帳號電話欄位。Threads 密碼不會交給 ThreadVault。

資料如何使用與保存

這些資料只用於帳號連接、同步、搜尋、顯示本人內容及回到原文。資料保存於 Supabase 雲端服務；Threads 授權 token 在伺服器加密保存，裝置上的登入憑證使用 iOS／Android 安全儲存。搜尋結果僅在本次 App 執行期間暫存，關閉 App 後清除。你的搜尋字詞會傳送至我們的搜尋服務處理，不用於廣告或追蹤。

服務提供者

Meta 提供 Threads 授權及本人內容 API；Supabase 提供登入、資料庫和伺服器服務；Expo 提供 App 建置服務；GitHub Pages 託管公開的產品、支援與政策頁，這些頁面不包含你的 Threads 貼文或授權 token。服務供應商可能為維運及安全保存必要的請求紀錄，例如 IP、時間及錯誤資訊。媒體圖片會由其原始伺服器載入。資料可能於你所在地以外處理。ThreadVault 不出售資料，不提供廣告，不使用第三方行為分析或跨 App 追蹤。

保留、解除連結與刪除

匯入內容會保存到你主動刪除帳號為止。解除 Threads 連結會移除我們保存的授權 token，但保留已同步的資料庫，方便你繼續搜尋。登出只移除此裝置的登入狀態。在「設定 → 刪除帳號與資料」完成確認後，會刪除 ThreadVault 的帳號、內容、授權 token、OAuth 狀態及同步紀錄，並清除 App 暫存；不會刪除 Threads 原始內容。供應商的備份或安全紀錄可能依其保留週期才清除。

你的選擇

你可不連接帳號，先使用明確標示的示範資料。示範內容為虛構，不會讀取你的 Threads。你可以隨時解除連結、刪除帳號，也可在 Threads 的網站權限設定移除對 ThreadVault 的授權。若有查詢、更正、匯出或刪除資料的需求，請透過支援頁聯絡我們；請勿寄送密碼或授權 token。

政策更新

若資料用途或權限有所改變，我們會更新此頁及日期；如新增必須取得同意的權限，會在使用前再次請你核准。ThreadVault 是獨立產品，並非 Meta 或 Threads 官方 App。
