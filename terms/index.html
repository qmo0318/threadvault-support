使用條款

更新日期：2026-10-08。使用前請了解服務範圍。

使用方式

ThreadVault 用來同步及搜尋你本人已獲授權的 Threads 內容。請只連接你有權使用的帳號，並遵守 Threads 與 Meta 的條款。

同步與可用性

同步會受網路、Meta API 權限、可回傳內容與速率限制影響，無法保證取得每一篇歷史內容。刪除或編輯原文未必即時反映在資料庫，請以 Threads 原文為準。ThreadVault 不應作為唯一的內容備份。

你的內容與權利

你的內容權利仍屬於你或原權利人。你允許 ThreadVault 在提供同步、搜尋和顯示服務所需範圍內處理內容。你可隨時刪除帳號及停止使用服務。

支援與變更

目前 App 免費使用。如未來有重大服務或收費變更，會在實施前說明。遇到問題請透過支援頁聯絡；個人資料處理方式以隱私政策為準。本條款不限制適用法律保障你的權利。
